# マスターデータ README(暫定・フェーズ2承認後に列定義を確定)

## 決定事項(ユーザー承認済)
- 対象年度: 令和元(2019)〜令和7(2025)の7年分(平成28〜30年度は使用しない)。試験日は2026-11-29。
- 特殊問題は集計から除外せず「別区分」とする(問題マスターに `特殊区分` 列を設ける)。
  - 2022-04: 正解なし / 2022-09: 複数正解(2,3) / 2020-23: 複数正解(1,3)
- ID規則: 問題=年度-問番号(2桁) 例 2025-01 / 肢=年度-問番号-肢番号 例 2025-01-3
- 集計・比較はコードで行う(LLMの暗算禁止)。

## ファイル
- 問題テキスト.jsonl: 350問の本文(scripts/extract_questions.py で生成。画像版PDFは対象外)
- 仕分け記録.csv: PDF仕分けの記録
- 論点分類表_案_v0.1.csv: 承認待ちの案(固定前)

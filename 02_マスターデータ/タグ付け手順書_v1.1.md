# 肢へのタグ付け手順書(v1.1・本番用)

## 目的
問題の1肢ごとに「論点ID」を1つ付ける。論点は `論点分類表.csv(v1.1・固定版。先頭列はバージョン)` に定義された50論点のみ(v1.1固定版)を使う。

## 入力
- 分類表: 02_マスターデータ/論点分類表.csv(v1.1・固定版。先頭列はバージョン)(論点ID・論点名・定義・含める例・含めない例)
- 対象: 肢ごとに 肢ID / 問題ID / 出題形式 / 設問文 / 肢本文 が与えられる。
  - 形式A=4択の各文、B=ア〜エの各文(組合せ/個数を問う設問の一部)、C=空欄補充の語句の組合せ。
  - 正解・正誤は与えられない(付けるのは論点であり、正誤ではない)。

## 手順
1. 設問文から、問われている法令・分野を把握する(例:「区分所有法の規定によれば」)。
2. 肢本文が実際に問うている“中心の論点”を1つだけ決める。設問文の分野ではなく、肢本文の内容で決める。
   - 例: 設問が区分所有法でも、肢が民法の相続を問うなら民法の論点にする。
3. 分類表の「定義」「含める例」「含めない例」を読み、最も合致する論点IDを選ぶ。
4. 迷った場合は、「含めない例」に書かれた“→論点ID”の指示に従う。
5. 肢が2つの論点にまたがる場合は、主たる論点を「論点ID」に、従たる論点を「副論点ID」に書く(無ければ空)。
6. どの論点にも当てはまらない場合は、無理に当てはめず「論点ID=なし」とし、理由をメモに書く。

## 禁止事項
- 分類表に無い論点IDを作らない。
- 条文番号・数値・条件を記憶で断定しない。根拠は『法令名』までとし、条番号は書かない(条番号は後工程で e-Gov により確認する)。
- 他のモデルの出力ファイルを読まない。

## 出力(JSON Lines・1肢1行・UTF-8)
{"肢ID":"2025-01-1","論点ID":"KS01","副論点ID":"","根拠法令":"区分所有法","確信度":"高|中|低","メモ":"迷った論点があれば(なければ空)"}
- 対象の全肢に1行ずつ出力する(欠落・重複なし)。

## v1.1で追加した判断ルール
- 「別段の定めの可否」を一覧で問う設問は、対象事項の論点で付ける(KS04は“別段の定め”自体を問う場合のみ)。
- 「規約改正の要否」を問う設問は、改正対象の事項の論点で付ける(KY09は付けない)。
- 物権変動・対抗要件(登記)・即時取得・契約解除はMN07。
- 迷ったら、各論点の「含めない例」の“→論点ID”に従う。

# 練習問題:給排水設備の構造方法(建設省告示第1597号)(全7問)

- 作成:AI(Sonnet)。**本試験の過去問ではなく、練習用の創作問題**。
- 根拠:国土交通省公表の建設省告示第1597号(`01_原本/告示/`)。告示は定性的な規定が中心で、試験で問われる数値(受水槽周囲60cm、マンホール立ち上げ10cm、吐水口・排水口空間、排水管の最小勾配、掃除口間隔、給水圧力など)の多くは**この告示に書かれていない**(空気調和・衛生工学会規格等が根拠)。本問題集はその範囲を含まない。
- 限界:問題の切り口・難易度は本試験と異なる。肢の言い換えの妥当性は人の確認を推奨。

## 問題

### 問1(PK-01 / 論点SB03)

次の記述のうち、建築物に設ける飲料水の配管設備及び排水のための配管設備の構造方法を定める件(昭和50年建設省告示第1597号)によれば、正しいものはどれか。

1. 給水タンク等の内部の保守点検を行うためのマンホールは、直径四十センチメートル以上の円が内接することができるものとしなければならない。
2. 圧力タンク等に設けるマンホールも、ほこりその他衛生上有害なものが入らないように有効に立ち上げなければならない。
3. 給水タンク等の天井がふたを兼ねる場合であっても、天井にマンホールを設けなければならない。
4. 給水タンク等の内部の保守点検を容易かつ安全に行うことができる位置に、直径六十センチメートル以上の円が内接することができるマンホールを設ける。ただし、外部から内部の保守点検を容易かつ安全に行うことができる小規模な給水タンク等はこの限りでない。

### 問2(PK-02 / 論点SB03)

次の記述のうち、建築物に設ける飲料水の配管設備及び排水のための配管設備の構造方法を定める件(昭和50年建設省告示第1597号)によれば、正しいものはどれか。

1. 給水タンク等の天井、底又は周壁は、建築物の他の部分と兼用することができる。
2. 給水タンク等の内部には、飲料水の配管設備以外の配管設備を設けないこと。
3. 有効容量が二立方メートル未満の給水タンク等にも、通気のための装置を必ず設けなければならない。
4. 給水タンク等を最下階の床下に設置する場合であっても、浸水を検知し警報する装置の設置その他の措置を講ずる必要はない。

### 問3(PK-03 / 論点SB03)

次の記述のうち、建築物に設ける飲料水の配管設備及び排水のための配管設備の構造方法を定める件(昭和50年建設省告示第1597号)によれば、正しいものはどれか。

1. ウォーターハンマーが生ずるおそれがある場合であっても、給水管には特段の措置を講ずる必要はない。
2. 給水立て主管からの各階への分岐管等主要な分岐管には、分岐点に近接した部分で、かつ、操作を容易に行うことができる部分に止水弁を設ける。
3. 給水立て主管からの各階への分岐管等主要な分岐管には、逆止弁を設けなければならない。
4. 主要な分岐管の止水弁は、分岐点から離れた、操作しにくい部分に設けるものとされている。

### 問4(PK-04 / 論点SB03)

次の記述のうち、建築物に設ける飲料水の配管設備及び排水のための配管設備の構造方法を定める件(昭和50年建設省告示第1597号)によれば、正しいものはどれか。

1. 排水トラップの深さは、二十センチメートル以上とする。
2. 排水トラップは、二重トラップとなるように設ける。
3. 排水トラップの深さは、五センチメートル以上十センチメートル以下(阻集器を兼ねる排水トラップにあつては、五センチメートル以上)とする。
4. 雨水排水管(雨水排水立て管を除く。)を汚水排水のための配管設備に連結する場合には、当該雨水排水管に排水トラップを設ける必要はない。

### 問5(PK-05 / 論点SB03)

次の記述のうち、建築物に設ける飲料水の配管設備及び排水のための配管設備の構造方法を定める件(昭和50年建設省告示第1597号)によれば、正しいものはどれか。

1. 排水槽の底の勾配は、吸い込みピットに向かって三十分の一以上二十分の一以下とする。
2. 排水槽の通気のための装置は、直接外気に衛生上有効に開放しなくてもよい。
3. 排水槽に設けるマンホールは、直径四十センチメートル以上の円が内接することができるものでなければならない。
4. 排水槽の底の勾配は、吸い込みピットに向かって十五分の一以上十分の一以下とする等、内部の保守点検を容易かつ安全に行うことができる構造とする。

### 問6(PK-06 / 論点SB03)

次の記述のうち、建築物に設ける飲料水の配管設備及び排水のための配管設備の構造方法を定める件(昭和50年建設省告示第1597号)によれば、正しいものはどれか。

1. 冷蔵庫、水飲器その他これらに類する機器の排水管は、排水管に直接連結してよい。
2. 給水タンク等の水抜管及びオーバーフロー管は、排水管に直接連結しないこと。
3. 雨水排水立て管は、汚水排水管又は通気管と兼用することができる。
4. 給水ポンプ、空気調和機その他これらに類する機器の排水管は、排水管に直接連結してよい。

### 問7(PK-07 / 論点SB03)

次の記述のうち、建築物に設ける飲料水の配管設備及び排水のための配管設備の構造方法を定める件(昭和50年建設省告示第1597号)によれば、正しいものはどれか。

1. 建築基準法別表第一(い)欄に掲げる用途以外の用途に供する建築物で、階数が三以下で、かつ、延べ面積が五百平方メートル以下のものについては、告示の規定の一部が適用されない。
2. 適用の特例の対象となる建築物の延べ面積は、千平方メートル以下である。
3. 建築基準法別表第一(い)欄に掲げる用途以外の用途に供する建築物で、階数が二以下で、かつ、延べ面積が五百平方メートル以下のものに設ける配管設備については、第一(第一号ロを除く。)並びに第二第三号イ及び第四号の規定は、適用しない。
4. 有効容量が五立方メートルを超える給水タンク等であっても、適用の特例により、給水タンク等に関する規定(第一第二号)は適用されない。

## 正解と解説

### 問1 正解:4

- 肢1【誤】誤り。直径六十センチメートル以上。 〔根拠:建設省告示第1597号 第一・二・イ(4)(ろ)〕
- 肢2【誤】誤り。内部が常時加圧される構造の給水タンク等(圧力タンク等)に設ける場合を除く。 〔根拠:建設省告示第1597号 第一・二・イ(4)(い)〕
- 肢3【誤】誤り。天井がふたを兼ねる場合は、この限りでない。 〔根拠:建設省告示第1597号 第一・二・イ(4)〕
- 肢4【正】正しい。第一・二・イ(4)(ろ)。 〔根拠:建設省告示第1597号 第一・二・イ(4)(ろ)〕

### 問2 正解:2

- 肢1【誤】誤り。兼用しない。 〔根拠:建設省告示第1597号 第一・二・イ(2)〕
- 肢2【正】正しい。第一・二・イ(3)。 〔根拠:建設省告示第1597号 第一・二・イ(3)〕
- 肢3【誤】誤り。有効容量が二立方メートル未満のものは、この限りでない。 〔根拠:建設省告示第1597号 第一・二・イ(8)〕
- 肢4【誤】誤り。最下階の床下その他浸水によりオーバーフロー管から水が逆流するおそれのある場所に設置する場合は、浸水を容易に覚知できる措置を講ずる。 〔根拠:建設省告示第1597号 第一・二・イ(7)〕

### 問3 正解:2

- 肢1【誤】誤り。エアチャンバーを設ける等有効な防止措置を講ずる。 〔根拠:建設省告示第1597号 第一・一・イ〕
- 肢2【正】正しい。第一・一・ロ。 〔根拠:建設省告示第1597号 第一・一・ロ〕
- 肢3【誤】誤り。止水弁を設ける(告示は逆止弁を規定していない)。 〔根拠:建設省告示第1597号 第一・一・ロ〕
- 肢4【誤】誤り。分岐点に近接した部分で、かつ操作を容易に行うことができる部分。 〔根拠:建設省告示第1597号 第一・一・ロ〕

### 問4 正解:3

- 肢1【誤】誤り。五センチメートル以上十センチメートル以下(阻集器を兼ねるものは五センチメートル以上)。 〔根拠:建設省告示第1597号 第二・三・ニ〕
- 肢2【誤】誤り。二重トラップとならないように設ける。 〔根拠:建設省告示第1597号 第二・三・ロ〕
- 肢3【正】正しい。第二・三・ニ。 〔根拠:建設省告示第1597号 第二・三・ニ〕
- 肢4【誤】誤り。排水トラップを設ける。 〔根拠:建設省告示第1597号 第二・三・イ〕

### 問5 正解:4

- 肢1【誤】誤り。十五分の一以上十分の一以下。 〔根拠:建設省告示第1597号 第二・二・ニ〕
- 肢2【誤】誤り。直接外気に衛生上有効に開放する。 〔根拠:建設省告示第1597号 第二・二・ホ〕
- 肢3【誤】誤り。直径六十センチメートル以上。 〔根拠:建設省告示第1597号 第二・二・ロ〕

### 問6 正解:2

- 肢3【正】正しい。第三(適用の特例)。 〔根拠:建設省告示第1597号 第三〕
